# What is it?
A simple filterscsript that creates a roadblock for a player when player is driving and wanted level is above 0. Changes the roadblock (skins, weapons, vehicles) when wanted level increaes. Uses GTA:SA nodes to find paths to the player from 3 possible directions where the player might be going. There are multiple safety checks that prevent a random car spawning right in front of a player as well as stops when a player is near to prevent the NPC from smashing into a random player.
